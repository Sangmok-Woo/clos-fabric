# LOG — 고장 훈련 기록

하루 한 줄. **날짜 · 증상 · 원인 · 해결**만 적는다. 길게 쓰고 싶어지면 그건 [RULES](RULES.md)(결정)나 [RUNBOOK](RUNBOOK.md)(절차)로 갈 내용이다.

- `./scripts/day.sh 답`을 치면 날짜와 문제 제목이 담긴 줄이 **맨 아래에 자동으로 붙는다.** 원인·해결 칸만 채운다
- 훈련이 아니라 실제로 겪은 고장도 같은 형식으로 적는다
- 요령: 증상은 **눈에 보인 것**(명령 출력), 원인은 **한 문장**, 해결은 **친 명령**
- 표가 파일 맨 끝에 있어야 자동 추가가 표 안으로 들어간다. 표 아래에는 아무것도 쓰지 않는다

| 날짜 | 증상 | 원인 | 해결 |
|---|---|---|---|

# 하루 5분 — Clos 패브릭 30일

슬럼프용이다. 새로 만들지 않는다. 이미 있는 랩을 **하루에 하나씩 고장 내고 고친다**.

시작 비용이 0이라는 게 이 방식의 핵심이다.
만드는 건 준비가 필요한데 부수는 건 준비가 없다. 명령 한 줄이면 오늘 몫이 시작된다.

## 하루 흐름 (5분)

```bash
cd /root/labs/clos-fabric
./scripts/day.sh
```

1. 오늘의 상황과 질문이 뜬다. **고장은 이미 걸려 있다.**
2. 답을 먼저 **예측한다.** (머릿속으로만. 이게 제일 중요한 단계다)
3. 화면에 뜬 확인 명령을 직접 쳐본다.
4. 다 봤으면:

```bash
./scripts/day.sh 답
```

정답과 해설이 나오고, 랩이 자동으로 원상복구되고, 진도가 하루 넘어간다.
기록은 `docs/41-하루5분-기록.md` 에 한 줄씩 쌓인다. 예측이 맞았는지만 채워 넣으면 된다.

**예측을 건너뛰면 이 30일은 아무 의미가 없다.** 답을 먼저 보면 그냥 읽기다.
빗나간 날이 곧 자기가 잘못 알고 있던 곳이고, 그 목록이 이 30일의 진짜 결과물이다.

## 명령

| 명령 | 하는 일 |
|---|---|
| `./scripts/day.sh` | 오늘 문제를 내고 고장을 건다 |
| `./scripts/day.sh 답` | 정답 + 해설 + 원상복구 + 진도 +1 |
| `./scripts/day.sh 12` | 12일차로 건너뛴다 (진행 중인 고장은 먼저 복구된다) |
| `./scripts/day.sh 목록` | 30일 전체 목록과 진도 |
| `./scripts/day.sh 상태` | 지금 며칠차인지, 고장이 걸려 있는지 |
| `./scripts/day.sh 복구` | 정답 안 보고 그냥 원상복구 |
| `./scripts/day.sh 재배포` | 랩을 통째로 다시 세운다 |

보조 도구:

```bash
./scripts/in.sh h1 ping -c 2 -s 1472 -M do 172.16.14.10
./scripts/in.sh leaf1 tcpdump -i eth1 -n -c 5 tcp port 179
```

`in.sh` 는 **호스트의 도구를 컨테이너 네트워크 안에서** 실행한다.
서버(h1~h4)가 alpine 이라 `ping -M do` 도 `ip neigh replace` 도 없고 `tcpdump` 는 아예 없어서 필요하다.
컨테이너의 "네트워크"라는 게 결국 리눅스 네임스페이스 하나일 뿐이라 가능한 일이다 — 프로그램은 호스트 것, 네트워크는 컨테이너 것.

## 시작 전에: veth 가 사라져 있으면

WSL 을 껐다 켰으면 **컨테이너는 떠 있는데 `eth1`~`eth4` 가 전부 없는** 상태가 된다.

왜 그러냐:
- WSL2 는 배포판 안에 돌아가는 프로세스가 하나도 없으면 배포판을 통째로 종료한다.
- 다시 켜지면 systemd 가 `docker.service` 를 재시작하고, 도커는 컨테이너의 네트워크 네임스페이스를 새로 만든다.
- containerlab 의 veth 는 도커가 만든 게 아니라 containerlab 이 따로 만들어 밀어 넣은 것이다. 도커는 그런 게 있었는지도 모른다.
- 그래서 도커가 아는 `eth0` 만 돌아오고 나머지는 사라진다.

`day.sh` 가 실행할 때마다 이걸 검사해서 알려주고, 잠자는 프로세스(`clos-keepalive`)를 하나 남겨 배포판이 꺼지지 않게 붙잡아 둔다.
그래도 링크가 없다고 뜨면:

```bash
./scripts/day.sh 재배포
```

## 이 30일이 노리는 것

명령어를 외우는 게 아니다. **자르는 순서**를 몸에 붙이는 것이다.

29일차에 쓰게 될 네 가지 질문:

1. **check.sh 의 어느 층이 깨졌나** — 세션? 경로 개수? 통신?
2. **한 방향인가 양방향인가** (8일차)
3. **즉시 실패인가 기다리다 실패인가** (15/16일차)
4. **안 되는 목적지들의 공통점은** (27일차)

이 네 개면 이 랩의 모든 장애가 두세 번 안에 좁혀진다.
실제 장애 대응도 구조는 같다 — 아는 명령의 개수가 아니라 자르는 순서가 실력이다.
